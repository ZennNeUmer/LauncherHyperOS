# Hyper Shell

Домашняя оболочка (замена системного лаунчера) для Android в стиле HyperOS:
жесты, меню приложений в виде пчелиных сот как на Apple Watch, отдельная панель
уведомлений со своими обоями, свободно перемещаемые и масштабируемые виджеты и
приложение настроек.

Написано на **Kotlin + Jetpack Compose**. Это самый быстрый практичный стек для
UI на Android: Kotlin компилируется в байткод/машинный код, а Compose рисует UI
через аппаратно ускоренный Skia без XML-инфляции и без накладных расходов
интерпретатора. Rust или C++ не могут напрямую управлять Android UI без
JNI-прослоек и всё равно упираются в Java/Kotlin-фреймворк, поэтому для такой
оболочки они медленнее в разработке и не быстрее в работе.

## Возможности

- **Главный экран** с доком, сеткой свободно расположенных виджетов, базовыми
  обоями (можно заменить своими) и иконкой настроек в правом верхнем углу.
- **Меню приложений** — гексагональная сетка иконок с зумом, панорамированием,
  поиском и анимацией появления. Открывается свайпом от правого края, свайпом
  вверх или кнопкой в доке.
- **Панель уведомлений** — свои обои (могут отличаться от главного экрана),
  размытие, быстрые переключатели (Wi‑Fi, Bluetooth, фонарик, «Не беспокоить»,
  автоповорот), ползунок яркости и список уведомлений со свайпом для удаления.
- **Виджеты** — четыре встроенных (часы, батарея, поиск, уведомления) и любые
  системные виджеты Android. Перетаскивание, изменение размера, удаление в режиме
  редактирования; положение сохраняется.
- **Настройки** — отдельное приложение: обои, акцентный цвет, эффекты, жесты,
  виджеты, док, скрытые приложения, разрешения и сброс.
- **Уведомления** читаются через официальный `NotificationListenerService`,
  root не нужен.

## Жесты

| Действие | Результат |
| --- | --- |
| Свайп влево от правого края | Меню приложений |
| Свайп влево по экрану | Панель уведомлений |
| Свайп вверх | Меню приложений |
| Свайп вниз в верхней части | Панель уведомлений |
| Свайп вправо в меню/панели | Закрыть панель |
| Долгое нажатие на пустом месте | Меню главного экрана |
| Долгое нажатие на иконке | Действия с приложением |
| Долгое нажатие на пустом месте → «Изменить виджеты» | Режим редактирования |

Каждый жест можно отключить в настройках. Жесты работают поверх виджетов, но не
мешают обычным нажатиям и прокрутке внутри виджетов.

## Сборка

Требования:

- JDK 17
- Android SDK: platform 34, build-tools 34.0.0
- Gradle 8.7 (или Android Studio Koala+)

Установка JDK 17 в Windows:

```powershell
winget install --id EclipseAdoptium.Temurin.17.JDK -e
```

После установки задайте `JAVA_HOME` на папку JDK (например,
`C:\Program Files\Eclipse Adoptium\jdk-17.0.21.9-hotspot`) и добавьте её `bin`
в `PATH`. Android Studio использует Gradle-обёртку из проекта, отдельная
установка Gradle не нужна.

### Android Studio

1. Откройте папку `HyperShell` как проект.
2. Дождитесь синхронизации Gradle.
3. Запустите конфигурацию `app` на устройстве или эмуляторе (Android 8.0+).

### Командная строка

```bash
# Windows (PowerShell)
.\gradlew.bat :app:assembleDebug

# Windows (cmd)
gradlew.bat :app:assembleDebug

# Linux / macOS
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

> После обновления APK HyperOS может сбросить лаунчер по умолчанию. Если кнопка
> «Домой» показывает выбор лаунчера, снова выберите **Hyper Shell** (или выполните
> `adb shell cmd package set-home-activity com.hyper.shell/.ui.LauncherActivity`).

Установка:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Если SDK установлен в нестандартное место, создайте `local.properties`:

```properties
sdk.dir=C\:\\Android\\Sdk
```

## Включение оболочки

1. Установите APK и запустите **Hyper Shell**.
2. Нажмите «Домой» — Android предложит выбрать приложение по умолчанию.
   Либо откройте «Настройки → Система → Жесты → Главный экран» (названия
   зависят от прошивки) и выберите **Hyper Shell**.
3. В приложении настроек откройте раздел **Система** и выдайте:
   - **Доступ к уведомлениям** — для списка уведомлений;
   - **Изменение системных настроек** — для яркости и автоповорота;
   - при необходимости разрешение **Камера** — для фонарика.
4. Раздел **Приложения** позволяет закрепить до пяти приложений в доке и
   скрыть лишние из меню.

## Структура проекта

```
app/src/main/kotlin/com/hyper/shell/
├── core/          Prefs (JSON + SharedPreferences), AppRepo, NotificationCenter
├── service/       NotificationListenerService
├── ui/
│   ├── theme/     цвета, типографика, glassmorphism, bounce-анимации
│   ├── components/ GlassCard, GlassButton, AppIcon, диалоги
│   ├── settings/  экраны настроек
│   ├── HomeScreen.kt, AppDrawer.kt, NotificationShade.kt, Widgets.kt
│   ├── Gestures.kt, Wallpaper.kt, LauncherScreen.kt
│   └── LauncherActivity.kt, SettingsActivity.kt
└── util/          кэш иконок
```

Состояние хранится в `SharedPreferences` в виде JSON и отдаётся как `StateFlow`,
поэтому лаунчер и настройки мгновенно видят изменения друг друга.

## Ограничения

- Полноценная замена системной панели уведомлений невозможна без root: системная
  шторка остаётся, Hyper Shell показывает свою внутри лаунчера.
- Системные виджеты хостятся через `AppWidgetHost`; некоторые виджеты могут
  некорректно себя вести при нестандартном размере.
- Размытие обоев панели уведомлений работает на Android 12+; на более старых
  версиях используется затемнение.
- Проект не использует сторонние UI-библиотеки, кроме Coil для загрузки
  выбранных обоев.
